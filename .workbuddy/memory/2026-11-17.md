# 2026-11-17

## 唱片架改为本地存储模式

- 提交 `feat:唱片架`（1f7b388，feature/album 分支，108 文件）。
- 将唱片架从「依赖本机服务端 /api/albums 读写」改为「静态清单 + localStorage」：
  - 新增 `scripts/sync-album-data.py`：读取 `public/albums/*/album.json`，生成 `public/album-data.js`（`window.ALBUM_DATA`），封面/动态封面转成 `/public/...` 相对路径。
  - `albums.html` 引入 `public/album-data.js`。
  - `albums.js`：新增 `displayUrl()` 处理本地相对路径（file:// 下去前导 `/`，http:// 下拼 origin）；`loadSavedAlbums` 改为读 `window.ALBUM_DATA` + localStorage（key `livelog-album-records-v1`）合并；`saveAlbum` 改为写 localStorage；删除 `usesLocalAlbumService` 及表单的 http 服务拦截。
- 效果：双击 `albums.html`（file://）即可查看已有唱片并添加新唱片；封面走本地相对路径 `<img>` 直接显示，动态封面 m3u8 在 file:// 下降级为静态封面。查询动态封面/保存封面文件仍需本机服务。
- 移除总花费统计的「未标币种」项（前后缀都识别不出币种的价格跳过）；统一统计字段字号（删除 `.stat-total strong` 独立的更小 font-size）。
- 修复 file:// 下封面不显示的 bug：`album_records.py` 的 `browser_record` 用 `quote(folder.name, safe='')` 把中文文件夹名百分号编码，file:// 下 `<img>` 把 `%E9%99%B6` 当字面文件名找不到磁盘上的中文目录。在 `albums.js` 的 `displayUrl` file:// 分支加 `decodeURI` 还原。
